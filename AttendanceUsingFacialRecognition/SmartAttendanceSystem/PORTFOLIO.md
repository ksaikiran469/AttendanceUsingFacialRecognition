# Portfolio description

**Smart Attendance System | Java, OpenCV, Swing, Maven, Apache POI**

Rebuilt an academic facial-recognition attendance application as a Java desktop project. Implemented consent-based face-image capture, OpenCV LBPH training and recognition, automatic attendance marking with duplicate prevention, and Excel report generation. Documented system architecture, local setup, and privacy limitations.

**Interview talking points:** Explain Haar Cascade detection vs. LBPH recognition; why unknown-face thresholds need tuning; duplicate attendance logic; local TSV storage tradeoffs; and why this is an educational demo rather than a production identity system.
